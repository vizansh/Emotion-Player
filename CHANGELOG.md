# 📜 Changelog

All notable changes to the **Emotion Player** project will be documented in this file.

## [1.0.0] - 2025-12-28
### ✨ Added
- **Core Engine:** Initial release of the `VibePipeline` with Aggressive Pooling.
- **Fusion:** `FusionEngine` integration for Gesture and Weather data.
- **Personalization:** `Personalizer` system with "Soul Profile" weight adjustments.
- **Documentation:** Professional `README.md` and `LICENSE` (MIT).

### 🛠️ Fixed (Planned for next build)
- **UI:** Reduced `RandomRotatedGestureSwipeHint` wave amplitude from 360f to 120f for better screen fit.
- **GPS:** Completed the `LocationSettingsClient` logic to ensure hardware GPS is toggled on during the Vibe Check.

### 🚀 Upcoming
- **Real-time Capture:** Wiring `PointerInput` to feed live X/Y/Pressure data into the `VibePipeline`.
- **Dynamic Feedback:** Adding a "Fusing Emotions..." animation state.
